## 使用方式

1. 确定用户目标、设备系统，以及个人设备或共享开发机场景。不要把“学习方法”解释为执行安装，把“整理指南”解释为上传工作记录。
2. 读取对应参考文档，使用指南已有的命令与页面入口。执行前可用 `aida version`、`aida help`、`aida status` 确认当前环境；不要编造指南未说明的参数。
3. 登录使用交互式 `aida login`；Token 不写入命令参数、文档或截图。安装脚本配置服务地址；核对 User 后再进行用户已要求的上传。
4. 个人 `upload --all` 与团队 `upload --team` 的归属不同。共享机按成员绝对工作目录分发，未配置目录不上传；不要因一次同步请求自行开启每日自动同步。
5. 报告使用用户确认的日期或周次。手选切片决定 Session 来源，筛选日期不裁剪切片。AI 生成会替换并自动保存正文，日报明日计划只能人工维护。若已有内容需要保留，先处理保留需求。
6. 以实际结果判断完成：安装确认命令可用；上传确认服务端状态；报告确认对应日期或周次的正文已保存。PROCESSING 时等待处理，不连续重复上传；FAILED/BLOCKED 保留错误摘要和时间，单条重试后仍失败则交给平台负责人。
