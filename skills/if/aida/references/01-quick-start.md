# 快速开始

来源：AIDA 指南中心；角色：工程师；提取日期：2026-10-14。

## 5 分钟生成第一份 AI 日报

从复制 Token、上传本地 Session，到在工作台生成并保存第一份日报。

### 完成目标

- 本机已经使用 Claude Code 或 Codex 完成过至少一段工作。
- 将对应 Session 上传到 AIDA。
- 在 AIDA 中生成、检查并保存第一份个人日报。

这条流程以“日报已经保存”为完成标准，而不是只完成客户端安装或 Session 上传。

### 1. 复制个人 Token

- 登录 AIDA。
- 点击右上角个人菜单。
- 选择“复制 Token”。
- Token 只用于本人设备登录，不要发送到群聊、需求、日报或截图中。

从右上角个人菜单复制 Token；页面不会展示 Token 明文。

### 2. 安装 AIDA 客户端

根据当前操作系统下载安装 AIDA。安装后重新打开终端，并检查命令是否可用。

Windows PowerShell 安装

```powershell
Invoke-RestMethod http://113.100.143.91:9180/statics-live/aida/install.ps1 | Invoke-Expression
```

macOS / Linux 安装

```bash
curl -fsSL http://113.100.143.91:9180/statics-live/aida/install.sh | bash
```

检查客户端版本

```text
aida version
```

### 3. 登录客户端

- 执行 aida login。
- 按提示粘贴刚复制的个人 Token；服务环境已由安装脚本自动配置。
- 执行 aida status，核对当前登录账号。

登录并检查状态

```text
aida login
aida status
```

### 4. 选择并上传 Session

- 执行 aida upload 进入全屏选择器，在选择器中检查项目、时间和摘要。
- 使用方向键或 j/k 移动，按 Space 勾选一到两条安全的 Session。
- 记录较多时按 / 输入项目、Session ID 或摘要关键词进行搜索；确认范围后按 Enter 开始上传。
- 确认目标 Session 显示 READY；如果显示 PROCESSING，请等待服务端处理完成，不要重复启动上传。

选择并上传

```text
aida upload
```

当前 AIDA 全屏选择界面。使用方向键移动、Space 勾选、/ 搜索，确认范围后按 Enter 上传；截图使用专用安全测试 Session。

### 5. 从工作台进入日报

- 回到 AIDA 工作台。
- 找到“报告处理”。
- 在“我的日报”右侧选择“填写日报”或“编辑日报”。

工作台的报告处理区提供个人日报入口。

### 6. 生成并保存日报

- 点击日报日期旁的日历图标，选择这份日报的归属日期。这里设置的是日报日期，不是 Session 筛选日期。
- 可以直接选择“AI 生成”；不选择 Session 时，系统会按日报日期冻结相对应的 Session 来源快照，再交给报告 Agent。
- 如果只想总结指定工作，打开“选择 session”抽屉；抽屉里的开始日期和结束日期只用于筛选候选 Session。
- 勾选需要的 Session 切片并关闭抽屉，再选择“AI 生成”。
- AI 生成完成后正文已自动保存。检查生成内容；明日计划仅由用户人工填写，修改后再选择“保存”。

弹窗顶部的日历选择日报归属日期；AI 生成和选择 Session 是并列操作，Session 选择不是必选步骤。

打开 Session 抽屉后，开始日期和结束日期只筛选候选 Session，不会修改日报日期。

### 完成检查

- “我的日报记录”出现目标日期。
- 展开后可以依次查看完整正文和明日计划。
- 仍可复制正文或再次编辑。

日报保存后会出现在个人日报记录中；展开后，明日计划显示在完整正文下方。

## 上传后为什么没有生成内容

从日期、上传结果和 Session 范围三处定位 AI 日报内容为空或不准确的问题。

### 依次检查

- 确认已在 aida upload 选择器中勾选目标 Session 并按 Enter，且结果显示 READY；仅打开选择器不会上传。
- 确认日报弹窗顶部选择的是要生成的日报日期；这不是 Session 筛选条件。
- 手动选择 Session 时，再在抽屉内使用开始日期和结束日期筛选候选记录。
- 未手动选择 Session 时，重新执行 AI 生成，让系统按日报日期重新冻结来源快照。
- 手动选择过 Session 时，检查是否勾选了正确切片；也可清空选择恢复按日期取数。
- 仍无内容时执行 aida status，确认客户端登录账号与当前网页账号一致。

### 容易误解的地方

上传 Session 不会自动创建日报。上传只准备生成上下文，仍需在工作台或日报页面选择“AI 生成”并保存结果。

## 登录或上传失败怎么办

处理找不到 aida 命令、身份不一致、本地没有 Session 和上传失败。

### 快速排查

- 找不到 aida：重新执行安装，关闭终端后再打开，并用 aida version 检查。
- 身份不正确：重新执行 aida login，并用 aida status 核对账号。
- 上传选择器为空：确认本机已使用 Claude Code 或 Codex 产生工作记录，然后重新执行 aida upload。
- 上传结果为 PROCESSING：服务端仍在处理，先等待再到 Session 页面确认，不要连续重复上传。
- 上传结果为 FAILED 或 BLOCKED：保留终端错误码和发生时间，再减少选择数量重试或联系平台负责人。
