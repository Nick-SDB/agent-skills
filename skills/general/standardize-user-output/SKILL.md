# 用户可见输出用语规范

## 核心原则

1. **直接说名词，不用比喻**：资源、指标、限制、对比，一律用正式名称直接描述，不用闸/门/臂/关卡/天花板这类隐喻词。
2. **数字带单位与口径**：给出精确值、单位、测量口径（实测/估算/上限），不写模糊的"很高/很低/爆了"。
3. **首次出现术语给一句话解释**：必要专业术语第一次出现时用一句话说明，之后才可单独使用。

## 术语替换表（禁止 → 改用）

| ❌ 避免（拗口 / 隐喻） | ✅ 改用（直接、专业） |
|---|---|
| 闸 / 门禁 / 闸门 / 关卡 | 阈值 / 上限 / 配额 / 限制，或直接说资源名（如"寄存器上限"） |
| 门槛（比喻义） | 阈值 / 判据 / 标准（如"3-CTA 门槛" → "3-CTA 阈值"） |
| 硬门 / 评测门 | 硬性判据 / 评测标准 / 必过标准 |
| A/B臂 | A/B 对比 / 基准对照 / 对照组 |
| 卡死 / 卡住（口语） | 受限 / 达到上限 / 触发限制 |
| 天花板（比喻义） | 上限 |
| 饿着 / 喂不饱（比喻义） | 利用率不足 / 空闲 / 供数不足 |

## 表达细则

1. **报告阈值 / 上限**：写"寄存器上限 255（每线程）"，不写"寄存器闸 255"。
2. **报告对比**：写"变体 A 相对基线：时间 1.97× 慢（0.124ms → 0.389ms）"，不写"A/B 臂"。
3. **报告限制 / 阻塞**：写"受 SMEM 限制，只能容纳 1 个 CTA"，不写"被 SMEM 门禁卡住"。
4. **报告占用 / 利用率**：写"occupancy 12.5%（实测，ncu）"，不写"占用率很低"。
5. **结论先给、证据随后**：一句话结论在前，数据与出处随后，用表格或列表呈现。

## 质量检查

交付前逐项核对：

- [ ] 没有 闸 / 门禁 / 关卡 / 臂 / 天花板 等隐喻或拗口词；
- [ ] 每个数字都有单位与口径（实测 / 估算 / 上限）；
- [ ] 专业术语首次出现有解释；
- [ ] 结论一句话能读懂，不需要回头查隐喻指什么。
